## 동작과 범위

- 선택값은 뒤로 이동하거나 요약에서 수정할 때 유지됩니다. 화면 흐름을 완전히 닫으면 초기화됩니다.
- 운동 가능 시간의 상관없어요는 다른 시간과 함께 선택되지 않습니다.
- 거주지 및 운동 시간 미입력, 운동 종목 미선택 시 다음 단계는 비활성화됩니다.
- 의료정보는 실제 조회·전송하지 않습니다. 병원명과 운동 안내는 Figma 예시이며 실제 의료적 판단에 사용하지 않습니다.
- 추천 요약의 무료 비용은 디자인 예시이며 실제 프로그램 요금 조회 결과가 아닙니다.
- 거주지 입력은 카카오 우편번호 서비스 웹뷰를 엽니다. 주소를 선택하면 도로명 주소를 지오코딩해 네이티브 지도와 핀으로 보여주고, `이 위치 사용`을 누르면 개인정보 입력 화면에 반영합니다. 카카오 서비스는 인터넷 연결이 필요하며, 공식 가이드의 모바일 웹뷰 권장 방식인 `embed`를 사용합니다.
- 카카오 지도 JavaScript API 키는 사용하지 않습니다. 주소 검색은 카카오 우편번호 서비스로, 선택 주소의 지도 표시는 iOS MapKit과 `CLGeocoder`로 처리합니다. 지오코딩이 실패해도 선택한 주소를 바로 적용할 수 있습니다.
- 원본 잎 벡터는 앱에 포함했습니다. 새 Figma 자산 다운로드가 네트워크 제한으로 불가능하여 운동·탐색 아이콘은 SF Symbols를 사용합니다.
- 약관 본문과 인증·추천·의료기관 서버는 제공되지 않았습니다. 로그인은 입력 형식 확인 데모이고 실제 계정을 생성하지 않습니다.
- 회원가입 흐름은 약관 동의 후 바로 개인정보 입력으로 연결됩니다.

## 검증

동의 로직 및 온보딩 모델 검사를 수행했습니다. 검사 범위는 입력 검증, 시간 배타 선택, 종목 선택, 의료정보 연결 분기, 요약 값, 10개 화면 매핑입니다.

SwiftUI 소스 타입 검사를 통과했습니다. 전체 Xcode 빌드는 작업 환경의 CoreSimulator 서비스 접근 제한으로 리소스 컴파일 단계에서 실패했습니다. 시뮬레이터 실행과 화면 시각 검증은 완료하지 못했습니다.
